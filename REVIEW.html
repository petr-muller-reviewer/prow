Context & Motivation

GitHub no longer sends notifications for @mentions in commit messages. The original reason for blocking PRs with @mentions was to prevent unintended notification spam — that reason no longer applies.

This PR removes the @mention check from the invalidcommitmsg and retitle plugins, retaining only the close-issue keyword check (fixes #N, closes #N, resolved #N, etc.).

Confirmed by GitHub staff.
