What this PR does

  • Replaces the unmaintained gopkg.in/robfig/cron.v2 with the maintained github.com/robfig/cron/v3 in go.mod/go.sum.
  • Adds an explicit cronParser var (with SecondOptional | Minute | Hour | Dom | Month | Dow | Descriptor) to both pkg/config and pkg/cron, needed because v3 no longer exposes a bare cron.Parse() function.
  • Passes the parser into cron.New() via cron.WithParser(cronParser) to keep the scheduler consistent with validation.
  • Updates the expected error message in a test case to match v3's slightly different format; adds two new test cases (5-field and 6-field) for cron validation.
  • Includes unrelated cosmetic test cleanup (var testCases = [] → testCases := [], blank line removals, struct literal reformatting).

Findings

Should fix cronParser duplicated across two packages

pkg/config/config.go:66-69 and pkg/cron/cron.go:33-36

Both packages independently define an identical cronParser with the same flags. If they ever diverge — e.g., someone adds a new flag in one place but not the other — config.validatePeriodics() would silently accept cron strings that pkg/cron rejects at runtime, or vice versa. The clean fix is to export the parser (or a parse helper) from pkg/cron and import it in pkg/config.

// pkg/config/config.go:66
var cronParser = cron.NewParser(
    cron.SecondOptional | cron.Minute | cron.Hour | cron.Dom | cron.Month | cron.Dow | cron.Descriptor,
)

// pkg/cron/cron.go:33 — identical
var cronParser = cron.NewParser(
    cron.SecondOptional | cron.Minute | cron.Hour | cron.Dom | cron.Month | cron.Dow | cron.Descriptor,
)

Nit TZ=UTC string prefix could use cron.WithLocation

pkg/cron/cron.go:156

The string prefix approach still works in v3 via the Descriptor flag, but v3 provides cron.WithLocation(time.UTC) as a first-class constructor option. Using it would make the UTC-enforcement explicit at construction time rather than embedded in every job spec string. Not broken as-is.
