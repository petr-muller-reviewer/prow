Direct. Import surface: pkg/plugins/testfreeze/checker/checker.go (fetches refs into in-memory storage via gitmemory.NewStorage()), test/integration/internal/fakegitserver/fakegitserver.go (test-only, uses git.PlainOpen → filesystem-backed dotgit storage).

Exposure: light.
Take
Safe to bump now.

Findings

Nitad-hoc org/repo split duplicates existing helpers

pkg/plugins/config.go:1373 (also cmd/checkconfig/main.go:1008,1545, cmd/deck/configured_jobs.go:83, cmd/deck/tide.go:193,272)

org, _, _ := strings.Cut(repo, "/")

Re-encodes pre-existing strings.Split(repo, "/")[0] logic instead of reusing pkg/config.SplitRepoName/NewOrgRepo. This duplication predates the PR and isn't introduced by this diff — and it's not a trivial swap, since SplitRepoName errors on a missing / (different semantics) and NewOrgRepo returns a struct, not a string. Optional drive-by cleanup only.

Nitunrelated commits bundled in one PR

commit structure: f7cf72fd8 (dep bump) + 01d8ac244 (lint refactor)

A security dependency bump is bundled with an unrelated lint-fix commit. Low real risk since either commit can still be reverted/cherry-picked independently by SHA, but splitting would keep the security-relevant history cleaner for future backports.
