What this PR does

  • Adds a new Assign config (map[string]*Assign) with only_org_members, action (warn/block), and exempt_labels fields.
  • In block mode, non-org-member /assign commands are rejected (members in the same command are still assigned).
  • In warn mode (default), the assign goes through but the bot posts a nudge comment.
  • Issues with configured exempt_labels bypass the restriction entirely (case-insensitive match).
  • When unconfigured, behavior is completely unchanged.

Since first review (2 revisions):

  • AssignAction type introduced with AssignActionWarn/AssignActionBlock constants; validateAssign() wired into Validate().

  • Dead nil check in newAssignHandler removed.
