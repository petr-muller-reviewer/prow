Followups

Report errors should exit nonzero

A requested report can fail during write or close after reconciliation. A local run targeting /dev/full logged ENOSPC and exited zero. Return a nonzero status and identify which operation failed. Preserve both errors when reconciliation and report delivery fail. cmd/peribolos/main.go:241-273.

Mark skipped reconciliation incomplete

Mark the report incomplete when listing repository invitations fails or an org membership update returns a swallowed 404. With null YAML permissions, Peribolos warns and leaves any existing grant alone. Decide whether this skip should also mark the report incomplete. If useful, clarify the user guide so it names the conditions that set complete: false and distinguishes them from ordinary dry-run discrepancies. cmd/peribolos/main.go:813-823, cmd/peribolos/main.go:1642-1648, cmd/peribolos/main.go:1691-1700, cmd/peribolos/main.go:1953-1958, site/content/en/docs/components/cli-tools/peribolos.md:196-204.

Account for successful failed-invitation cleanup

Peribolos can successfully delete a failed invitation before attempting a reinvite. The deletion is omitted from the report. A failed reinvite can leave the changes array empty despite the deletion. Record the deletion as invitation cleanup or explicitly scope that operation out of the documented coverage. cmd/peribolos/main.go:802-823.

Preserve a nested team's configured parent on metadata edits

Track this as an independent reconciliation bug. The existing team PATCH sets parent_team_id: null on a description-only edit when the current parent matches the configured parent. This can detach the team while the report lists only description. Send the configured parent ID on the PATCH and test that request. cmd/peribolos/main.go:1877-1908, pkg/github/client.go:4072-4080.

Optionally guard against an output path that aliases an input

I reproduced the overwrite with each of a temporary config and a temporary token. The destination must resolve to an input file for this to happen. As optional hardening, compare file identities before truncating the destination. cmd/peribolos/main.go:201-224.
