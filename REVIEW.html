Verdict: APPROVE

A correct, minimal two-line bug fix that restores CLA label functionality for GitHub Apps auth installations. The change follows the exact same pattern already used by blunderbuss, trigger, and welcome plugins. No concerns from code quality, maintainability, or deployment risk perspectives. Should be merged promptly as it fixes a production-blocking issue.

What this PR does

  • Switches the CLA plugin from FindIssues() to FindIssuesWithOrg(), passing the org explicitly from the status event payload.
  • Fixes the root cause: FindIssues delegates to FindIssuesWithOrg("", ...), and the apps auth roundtripper requires a non-empty org to look up the correct installation token.
  • Updates the local gitHubClient interface to declare FindIssuesWithOrg instead of FindIssues, preventing future accidental use of the org-less variant in this plugin.
  • No configuration, API surface, or behavioral changes for operators. Under OAuth auth the behavior is identical.
