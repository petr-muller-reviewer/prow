Verdict: request changes

The role reconciliation path can revoke organization roles from teams the operator explicitly excluded via --ignore-secret-teams or --ignore-enterprise-teams. This is a silent permission change in an opt-in path and should be fixed before merge.

What this PR does

  • Adds a roles: section for declarative assignments of existing GitHub organization roles.
  • Adds --fix-org-roles and GitHub client methods to list and synchronize team and user assignments.
  • Normalizes role/user identifiers, validates role configuration, and skips pending invitees.
  • Extends --dump to emit role assignments while omitting unavailable role data and ignored teams.

configureTeams omits secret/enterprise teams when the respective ignore flag is enabled, leaving them out of githubTeams and wantSet. The role API still returns their assignments, which enter haveSet and are deleted. A configured role held by a managed and an ignored team consequently revokes the ignored team’s assignment, contrary to the ignore flag contract. The latest commit fixes dump output only; pass ignored slugs into reconciliation and exclude them from toRemove.
