Verdict

Safe to bump now — approve.

Dep-only bump of google.golang.org/grpc v1.84.0 → v1.85.0 plus the indirect envoyproxy/go-control-plane/envoy pin that grpc 1.85.0 requires. The release is 27 days old and properly tagged, OSV has no advisories at either version, and none of the changed APIs are used by prow. The server fixes in 1.85 land directly in gangway's gRPC server (stream-ID handling, HEADERS+EndStream hang, missing :authority rejection, forceful Stop()), so this is a net hardening rather than a risk.

  • Bumps the direct dependency google.golang.org/grpc from v1.84.0 to v1.85.0 (go.mod:74).
  • Pulls the indirect github.com/envoyproxy/go-control-plane/envoy pin from the v1.39.0 tag to pseudo-version v1.39.1-0.20260819172001-e6e3fd93e4be, as required by grpc 1.85.0's own go.mod; nothing in prow selects this version.
  • Touches only go.mod and go.sum (6 insertions, 6 deletions); no vendor tree exists and no project code or generated artifacts change.
  • Brings in grpc server hardening (Stop() during GracefulStop(), HEADERS+EndStream, RFC 7540 stream-ID increment, requests without :authority/Host), transport control-buffer throttle tuning, and a retry :authority fix for xDS load balancers (not used here).
