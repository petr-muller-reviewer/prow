Verdict

Approve. Clean, behavior-preserving refactoring that consolidates dry-run bypass logic into a single function. The removed guard in IsAppInstalled was provably redundant. Test coverage added for the changed path.

What this PR does

  • Moves the r.method == http.MethodGet check from the inline condition in requestRawWithContext into isDryRunAllowed, making it the single source of truth for what passes in dry-run mode.
  • Removes a stale c.dry guard from IsAppInstalled — it uses a GET request that was never blocked by requestRawWithContext anyway.
  • Adds a dry-run subtest to TestIsAppInstalled that verifies GET requests actually reach the test server (not short-circuited to defaults).
  • Updates the isDryRunAllowed doc comment to reflect the new GET-first logic.
