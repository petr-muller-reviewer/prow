Analysis

Probable cause / design issue

Classic tri-state-boolean anti-pattern: two independent *bool fields represent three mutually exclusive states. The doc comment claims UseInsecureHTTP is "overridden" by SSH, but this precedence is never validated in code — if both are true, SSH silently wins and UseInsecureHTTP is never even read.
