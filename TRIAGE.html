Verdict

Accepted. Valid cleanup proposal to remove four obsolete plugins/commands with deprecated or unmaintained dependencies.

This is a legitimate tech debt cleanup issue filed by a project member (upodroid). It targets four components that are either deprecated, superseded by GitHub-native features, or no longer used by any known Prow deployment. All four exist in the codebase. The issue has active maintainer discussion (petr-muller, BenTheElder) about the deprecation and removal process, but no PRs yet. The primary blocker is maintainer alignment on phased deprecation vs. immediate removal for the simpler components.

What the issue reports

  • Prow carries plugins and commands that are no longer needed or have been superseded by GitHub-native features.
  • The golint plugin uses golang.org/x/lint, which is deprecated; repos should run golangci-lint as a CI job instead.
  • The dco plugin checks for Signed-off-by trailers, but GitHub now offers native DCO enforcement as a repository setting.
  • The jenkins-operator bridges ProwJobs to Jenkins, which is no longer used by the Prow community.
  • The buildifier plugin formats Bazel files, but Prow no longer uses Bazel; it pulls an unmaintained dependency pinned to a 2020 commit.

buildifier (pkg/plugins/buildifier/)

Standalone plugin, zero coupling. Uses github.com/bazelbuild/buildtools v0.0.0-20200922170545-10384511ce98 (unmaintained, 2020 commit). Registered via blank import in cmd/hook/plugin-imports/plugin-imports.go:28 and pkg/hook/plugin-imports/plugin-imports.go:28. Removal is purely mechanical: delete the package, remove imports, clean up go.mod.

golint (pkg/plugins/golint/)

Uses deprecated golang.org/x/lint v0.0.0-20241112194109-818c5a804067. Runs at Prow's Go version, not the target repo's — fundamentally broken for a linter. The AddedLines() function at pkg/plugins/golint/golint.go:340-377 is a general-purpose diff parser imported by pkg/plugins/verify-owners/verify-owners.go:39,221. This must be relocated (e.g., to a shared utility package or inlined into verify-owners) before golint can be deleted.

dco (pkg/plugins/dco/)

GitHub now offers native DCO enforcement. However, the native setting enforces at push time (--signoff required), while the plugin retroactively checks all commits in a PR. This functional difference was raised by valen-mascarenhas14 in the issue. MarkdownSHAList() is used by pkg/plugins/invalidcommitmsg/invalidcommitmsg.go:32,158,166 and must be relocated or inlined before removal.

jenkins-operator (cmd/jenkins-operator/, pkg/jenkins/)

~1600 lines of code bridging ProwJobs to Jenkins. Wired into:

  • pkg/config/config.go:177 — JenkinsOperators []JenkinsOperator config field, validation at config.go:2563-2576
  • pkg/apis/prowjobs/v1/types.go:91 — JenkinsAgent = "jenkins" agent type, JenkinsSpec at types.go:192, JenkinsBuildID at types.go:1141
  • Deck log routing references jenkins-operator's HTTP endpoint

Despite the wiring, integration is shallow: only cmd/jenkins-operator/ imports pkg/jenkins/. No other operator depends on it.

Deprecation mechanisms available

  • Announcements page: site/content/en/docs/announcements.md documents breaking changes. Precedent: requiresig removed, docs-no-retest deprecated Jan 2020 / removed April 2020.
  • Runtime warnings: pkg/logrusutil/logrusutil.go:127-128 provides ThrottledWarnf().
  • Config warnings: pkg/plugins/config.go has patterns for deprecated config fields (e.g., TrustedOrg at line 564).
  • checkconfig: cmd/checkconfig/main.go:79-420 has --warnings/--exclude-warning/--strict flags, but no plugin-specific deprecation checks yet.

Maintainer discussion

petr-muller proposed phased deprecation: announce with a date, add runtime warnings, then remove. Prefers graceful degradation on removal (checkconfig rejects but hook still starts). BenTheElder agrees linters should just be ripped out immediately — nobody is using them and the design is broken. Prefers hard failure so operators notice. Both agree on using announcements.md as a starting point.
