✅ Accepted — legitimate bug, effort level 1, author has volunteered a PR.

This is a precisely-diagnosed nil-pointer panic in pkg/git/v2/publisher.go plus a small usability gap in pkg/flagutil/github.go, both confirmed by reading current main. The fix is small, well-scoped, backwards compatible, and matches an existing "fail-with-error, not panic" contract elsewhere in the same package.

What the issue reports

  • RepoClient.Commit panics with a nil pointer dereference when the underlying GitUser getter was never configured.
  • The panic hits specifically for clients built via flagutil.GitHubOptions.GitClientFactory(...), the common in-repo helper — it wires Username/Token for clone/push but never GitUser for commit.
  • WithGitUser (added in #507) exists and works, but is only reachable via the lower-level gitv2.NewClientFactory/NewLocalClientFactory constructors, not through GitHubOptions.GitClientFactory.
  • Author's workaround: build two factories on the same working tree — the GitHub-authenticated one for clone/push, and a second manual gitv2.NewClientFactory(WithGitUser(...)) used only for .Commit().
  • Author proposes nil-guarding publisher.Commit and letting GitHubOptions.GitClientFactory accept/forward a GitUser getter; offered to send a PR.

Analysis

Reproducibility / observed behavior

Reproduces unconditionally, no timing dependency: any client built via GitHubOptions.GitClientFactory(...) has GitUser unset, so calling .Commit(...) panics every time — no special config beyond "don't have GitUser set," which is the only state reachable through that helper today.

Probable cause

p.info is a GitUserGetter (func() (name, email string, err error)), non-nil only if clientFactory.gitUser was set. ClientFactoryOpts.GitUser is applied only if cfo.GitUser != nil (client_factory.go:177-178) — the chain is designed to tolerate an absent GitUser, deferring failure to first use. Commit violates that "fail-with-error" contract by panicking instead of returning an error. Separately, GitHubOptions.GitClientFactory (github.go:340-365) sets Censor, CookieFilePath, Host, Persist, SigningKeyPath, and conditionally Username/Token — never GitUser — and offers no parameter to supply one.
