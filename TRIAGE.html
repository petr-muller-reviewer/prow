Verdict

Resolved. Prow now has a generic, configurable Markdown lens. A Spyglass config convention can route a job's DEBUGGING.md artifact to that lens, surfacing rendered guidance with the test results. The maintainer comment on 2026-10-13 agrees this makes the request possible and asks whether further Prow changes are needed; no further code change is required for the capability described here.

Resolution

Classification: sufficient. PR #695, merged 2026-05-11, introduced the generic Markdown lens. Spyglass configuration matches artifacts with RequiredFiles regexes and selects a lens by name, so a shared convention can match DEBUGGING.md and use markdown. The lens has priority 5, placing it among the higher-priority views. The issue presented a semi-collapsed viewer as an example and explicitly allowed any way to signal useful content in artifacts; a configured Markdown view addresses that request. The convention must be enabled in the relevant Prow config and jobs must emit the file.

What the issue reports

  • Useful debugging artifacts such as component logs and metrics are collected but are hard for contributors to discover behind the general artifacts link.
  • The author proposed a job artifact named $ARTIFACTS/DEBUGGING.md, rendered near the top of the Spyglass results with links to relevant documentation.
  • The author also accepted a less specific signal that encourages users to inspect artifacts; discussion favored guidance emitted by reusable job tools over requiring every job owner to write it.
