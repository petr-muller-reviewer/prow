Verdict

accepted — This is a reproducible bug in Prow's ghcache request coalescer. Keep the issue open while PR #1023 is reviewed; close it after the fix merges.

What the issue reports

  • ghcache coalesces overlapping GET requests to the same URL using an in-flight key that ignores Accept.
  • GitHub serves pull-request JSON, diff, and patch representations from the same endpoint, selected by Accept.
  • When requests for different representations overlap, a caller can receive the other request's body.
  • The reporter supplied a concurrent regression test and reports it failed in five of five runs on main.

Findings

reproducibilityConcurrent requests return the wrong representation

  • detail: The issue includes a fake RoundTripper test that delays the JSON response, starts a diff request to the same URL, and checks the diff body. The reporter reports the test failed five of five times on main; this triage did not rerun it.
  • evidence: kubernetes-sigs/prow#1020 issue body.

causeIn-flight key omits Accept

  • detail: requestCoalescer.RoundTrip indexes active GET requests by URL alone. A matching request subscribes to the first and reconstructs its response from the first request's saved bytes, so different media types can share a response.
  • evidence: pkg/ghcache/coalesce.go:97-100,105-170.
