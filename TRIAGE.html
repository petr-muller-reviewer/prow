Verdict

Accepted — legitimate feature request, keep open.

The issue asks for a documented, non-HTML way to learn Tide's verdict and blocking reasons for a specific PR, aimed at AI/agent integrations that otherwise have to scrape the /tide dashboard or infer status from generic GitHub APIs. Tide/Deck already compute most of the needed data internally, but no existing endpoint returns it per-PR in a structured form — this is a real, scoped gap, not a misconfiguration or duplicate.

What the issue reports

  • No official API exists to get Tide's verdict for a given PR without a headless browser.
  • Current workarounds (inferring status from generic GitHub APIs) are error-prone and inefficient, especially for AI-driven integrations.
  • Author is specifically after Tide's blocking conditions — e.g. missing labels, failing required tests — not just pass/fail.
  • Author checked and could not find an existing endpoint for this.

Analysis

Probable cause / gap

Tide already has two building blocks, but nothing connects them into a per-PR structured answer:

  • Pool-shaped JSON dumps (/tide.js, /tide-history.js) — bulk, not keyed by PR, no reason field.
  • A free-text "why not mergeable" string, only ever surfaced as a GitHub commit-status description.
